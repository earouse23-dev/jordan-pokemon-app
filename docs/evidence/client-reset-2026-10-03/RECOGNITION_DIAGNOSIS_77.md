Investigation only. No application/configuration correction, deployment, SQL, customer write, paid provider call or dependency change was made. Current production remains checkpoint76, deployment `dpl_DwAyhZZZLfCDKpn248uJQ5eaY2Wk`. Existing evidence and customer records remain intact.

## Confirmed production blocker

The hosted OCR worker receives `script-src 'self'`, which prohibits its WebAssembly engine from compiling. Actual shipped worker initialization on the canonical production origin fails in both Chromium and WebKit. WebKit reports: `Refused to create a WebAssembly object because 'unsafe-eval' or 'wasm-unsafe-eval' is not an allowed source`. The application suppresses the initialization error and eventually shows **Reading took too long · try a closer photo**. Moving closer cannot fix this failure; matching is never reached.

Controlled isolation: intercept only the worker response in an owned diagnostic browser and add the narrow `wasm-unsafe-eval` permission. The same shipped chunk/worker then reads `Pikachu 025/165` in 913ms Chromium / 670ms WebKit. Hosted settings remain untouched. Replaying the real preparation → OCR → live read-only catalog → detail navigation with this isolated worker policy opens Japanese Charizard in 1,430ms / 1,023ms. With the current policy, the same input instead times out at 5,015ms / 5,007ms without any catalog request.

This is not an absent AI credential or a PkmnPrices Pro connection failure. Intake uses installed local OCR; paid cloud vision remains intentionally held. [CSP WebAssembly policy documentation](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/script-src) explains the narrow permission; broad JavaScript `unsafe-eval` is not required by this isolation result.

Previous verification missed this because the local browser harness lacked production response headers. Checkpoint76 fixed the split-build CommonJS import failure, but did not establish that the engine could run under the deployed security policy. That completion evidence was insufficient.
