## Reproducible native build path and hard limits

Current neutral artifact can be regenerated without an environment file:

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run build:native
npm run sync:native
npm run verify:native
```

A configured **test** bundle requires a reviewed, explicit nonsecret JSON file: `node scripts/build.mjs --native --public-config=/absolute/path/to/reviewed-public.json`; then sync and verify. Do not use the placeholder example as real configuration. The selected developer directory was `/Library/Developer/CommandLineTools`; retained [preflight](sol-client-07/preflight.json) found no usable Xcode/simctl or discovered full Xcode. Neither simulator build/launch nor physical iPhone/signing could be run. Once a real Xcode path is available, the generated project/scheme support this proposed unsigned simulator command (not yet executed):

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project ios/App/App.xcodeproj -scheme App -configuration Debug -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' -derivedDataPath /tmp/mica-client07-derived CODE_SIGNING_ALLOWED=NO build
```

The exact Xcode path, version, simulator and compile result must be verified at that gate. Do not substitute browser WebKit for WKWebView/device evidence.
