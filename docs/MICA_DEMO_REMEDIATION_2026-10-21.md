## What changed

- **One saved dashboard:** version 4 stores bounded top-holding presentation and native-currency performance beside the existing total and history. Total, chart, top positions and all-time P/L now render from the same published revision, including before inventory arrives. Delayed reads cannot roll back a newer revision. Old versions rebuild from retained pricing, then allow that day's normal refresh immediately; real pricing failures keep retry backoff. Summary responses exclude detailed pricing/evidence. Logout/account switch clears the former owner's local saved view.
- **Honest chart endpoints:** today's display endpoint preserves purchase-cost estimates and coverage. Carried-forward observations are marked and labelled with their actual valuation date; ordinary reads do not rewrite stored history. Rendering includes today's date in its cache key. Existing daily source caching and budget reservations remain in force.
- **Phone detail hierarchy:** a 44px copy-title icon sits beside the card name, preserving complete exact identity without a separate row. Removed duplicate external-link decoration. Owned-copy actions stay within reach at the bottom with safe-area spacing. Existing mobile chart-position acceptance passes without weakening the limit or shrinking type/chart to hide the problem.
- **Search and settings:** accessible search names distinguish language, edition and finish. Secondary collection tools sit in one optional disclosure. Currency saves on selection, preserves the chosen value on failure, and offers Retry save without overwriting hidden legacy preferences.
- **Update recovery:** a waiting web release offers Reload/Later. It does not automatically reload unfinished intake, open sheets, onboarding or an unsaved currency selection. Native builds retain their separate update path.
- **Security and diagnostics:** patched the existing production HTTP dependency resolution from undici 7.29.0 to 7.30.1. Health/capability diagnostics distinguish configured-but-unverified identification from held grading; configuration is not reported as successful feature acceptance. Corrected the absolute camera claim that photos are never saved.
- **Publication safeguard:** generated release artifacts retain the verified existing Vercel project/team link, and routing verification rejects a mismatch before publication.
